
# 🕷️ SPIDER-MD

**A Lightweight, Modular WhatsApp Bot**

SPIDER-MD is a WhatsApp automation bot built with JavaScript, Node.js, and the Baileys library.

## ✨ Features

- 📱 WhatsApp connection using Baileys
- ⚡ Ping command
- 🧩 Modular plugin structure
- 🔧 Easy configuration
- 🚀 Simple startup process

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/blix-xer/SPIDER-MD.git
cd SPIDER-MD
```

Install dependencies:

```bash
npm install
```

Start the bot:

```bash
npm start
```

## ⚙️ Configuration

Edit `src/config.js` to configure your bot settings, including its command prefix.

## 💬 Available Commands

| Command | Description |
|---|---|
| `.ping` | Check bot response |
